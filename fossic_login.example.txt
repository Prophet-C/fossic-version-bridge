#   1. 用浏览器登录 https://www.fossic.org ，打开任意一个帖子页面

#   3. 点列表最上面那条请求（thread-xxxx 那个），在右边「请求标头 / Request Headers」里：
#        cookie:      整行复制它的值
#        user-agent:  整行复制它的值
#   必须用同一个浏览器的这两个值：fossic 会核对登录信息和浏览器是否匹配。
